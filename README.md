# INCY VPN App Sync

Удобный BAT-скрипт для Windows, который автоматически добавляет исполняемые файлы выбранных программ в список приложений INCY, работающих через VPN.

Скрипт рекурсивно находит все `.exe` в указанных папках, обновляет настройки INCY и создаёт автоматическую синхронизацию при входе в Windows. В меню есть русские объяснения и примеры для каждого действия.

> [!IMPORTANT]
> **Добавлять программы и запускать синхронизацию нужно при полностью закрытом INCY.** Закройте INCY через значок в системном трее и пункт **«Выход»** — простого отключения VPN или закрытия окна недостаточно. Если INCY продолжает работать, он может перезаписать файл настроек своей старой копией из памяти и удалить добавленные BAT-файлом программы.

## Главное

- Ищет все `.exe` в папке программы и её подпапках.
- Поддерживает обычные пути, путь к одному `.exe` и шаблоны со `*`.
- Уже содержит шаблоны для Google Chrome, Discord и ChatGPT/Codex.
- Делает резервную копию настроек перед изменением.
- Создаёт задачу Windows для автоматического обновления списка после входа в систему.
- Сам не закрывает и не перезапускает INCY: перед изменением списка пользователь должен полностью выйти из приложения.
- Не добавляет одинаковые пути повторно.

## Требования

- Windows 10 или Windows 11.
- Установленный INCY.
- Права администратора для первой установки и создания задачи автозапуска.

## Быстрый запуск

1. Скачайте [`VPN-программы.bat`](./VPN-программы.bat).
2. Полностью закройте INCY через значок в системном трее и пункт **«Выход»**.
3. Запустите BAT двойным щелчком.
4. Подтвердите запрос контроля учётных записей Windows.
5. Добавьте нужную программу через пункт **2**.
6. Выберите пункт **1 — Синхронизировать сейчас**.
7. Закройте BAT.
8. Запустите INCY и подключите VPN.
9. Запустите добавленную программу.

При первом запуске скрипт установит фоновую копию и создаст задачу **INCY VPN Application Sync**. Если INCY запускается одновременно с этой задачей и не принимает изменения, используйте ручную последовательность выше.

## Как добавить программу

Сначала полностью закройте INCY через значок в трее и пункт **«Выход»**. Затем запустите BAT и выберите пункт **2 — Добавить программу, папку или EXE**.

Можно вставить путь к папке:

```text
C:\Program Files\Моя программа
```

Можно вставить путь к конкретному EXE:

```text
C:\Program Files\Моя программа\program.exe
```

В этом случае скрипт сохранит папку, в которой находится EXE, и найдёт в ней все остальные исполняемые файлы.

Можно использовать шаблон для папок с меняющимися версиями:

```text
C:\Users\Имя\AppData\Local\Моя программа\app-*
```

Кавычки вокруг пути можно оставить. После добавления выберите пункт **1 — Синхронизировать сейчас**, закройте BAT и только затем снова запустите INCY.

## Пункты меню

### 1. Синхронизировать сейчас

Повторно сканирует все сохранённые папки и записывает актуальный список EXE в INCY.

Пример: Discord обновился и установился в папку новой версии — выберите пункт 1.

Перед синхронизацией полностью выйдите из INCY. Если приложение работает в фоне, оно может затереть новый список.

### 2. Добавить программу, папку или EXE

Сохраняет новый путь или шаблон. Все EXE внутри указанной папки и её подпапок будут найдены автоматически.

Пример: добавьте папку Telegram Desktop, а затем выполните синхронизацию.

### 3. Показать сохранённые папки

Показывает встроенные шаблоны и все пути, добавленные пользователем.

Пример: используйте этот пункт, чтобы проверить, сохранён ли Telegram.

### 4. Удалить папку из списка

Показывает нумерованный список и просит номер записи для удаления. Само приложение и его файлы не удаляются — исчезает только правило сканирования.

Пример: если Telegram больше не должен работать через VPN, удалите его правило и выполните синхронизацию.

Будьте внимательны: если удалить встроенное правило Chrome, Discord или ChatGPT/Codex, соответствующая программа исчезнет из списка после следующей синхронизации.

### 5. Починить автосинхронизацию

Заново устанавливает фоновую копию скрипта и задачу Windows.

Пример: используйте этот пункт, если автоматическое обновление списка при входе в Windows перестало работать.

### 6. Восстановить резервную копию

Возвращает файл настроек INCY к состоянию перед последней синхронизацией.

Пример: если после изменения списка настройки стали неправильными, используйте этот пункт как аварийный откат.

### 0. Выход

Закрывает только окно скрипта. INCY и VPN продолжают работать.

## Где хранятся данные

Пользовательские шаблоны, история синхронизации и резервные копии:

```text
%LOCALAPPDATA%\INCY-VPN-Sync
```

Установленная фоновая копия и журнал задачи:

```text
C:\ProgramData\INCY-VPN-Sync
```

Скрипт изменяет файл:

```text
%APPDATA%\incy\preferences.json
```

Из настроек изменяются только поля списка приложений для VPN:

- `perAppProxyEnabled`
- `perAppProxyMode`
- `perAppProxyApps`

## Важное ограничение

Скрипт изменяет файл настроек INCY напрямую. Запущенный INCY хранит собственную копию настроек в памяти и при переподключении может записать её поверх изменений BAT-файла.

Поэтому надёжный порядок такой:

1. Полностью выйти из INCY через системный трей.
2. Запустить BAT, добавить программы и выполнить синхронизацию.
3. Закрыть BAT.
4. Запустить INCY и подключить VPN.

Обычного отключения и повторного подключения VPN недостаточно, если список был изменён BAT-файлом во время работы INCY.

## Удаление автосинхронизации

1. Откройте **Планировщик заданий Windows**.
2. Удалите задачу **INCY VPN Application Sync**.
3. При необходимости удалите папки `C:\ProgramData\INCY-VPN-Sync` и `%LOCALAPPDATA%\INCY-VPN-Sync`.

Перед удалением папки из `%LOCALAPPDATA%` сохраните нужные резервные копии.

## Безопасность

Исходный код полностью находится в одном BAT-файле. Перед запуском его можно открыть Блокнотом и проверить. Скрипт не загружает файлы из интернета и не отправляет пользовательские данные.
